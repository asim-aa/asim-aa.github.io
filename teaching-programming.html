Teaching Programming Portfolio

EDS 124 — Teaching Computational Thinking for Everyone

This portfolio documents my work and learning in EDS 124 at UC San Diego. As a Mathematics–Computer Science student, I want to understand how to explain technical ideas clearly to people with different levels of programming experience.

Overview

About this portfolio

Throughout the course, I'll collect programming activities, teaching demonstrations, videos, projects, reflections, and lesson materials about computational thinking.

Learning how beginners approach code helps me communicate across technical backgrounds and design more approachable software experiences.

The Disclosure Verifier

Catches SEC disclosure inconsistencies before the company itself admits them.

Agentic system design · MCP tools · DSPy optimization · RLVR fine-tuning

An agentic pipeline that extracts every quantitative claim from a company's SEC MD&A prose and reconciles it against that filing's own structured XBRL data, with exact citations. Three custom MCP tool servers handle filing retrieval, MD&A extraction, and numerical reconciliation; a DSPy-optimized ChainOfThought signature does the extracting; and a hierarchical Coordinator → Extraction → Verification → Reconciliation pipeline enforces a budget and checkpoints so a crash never loses progress. Backtested against 13,827 real SEC restatement fingerprints across 541 companies, it matched 122 real prose instances and would have flagged 96.7% of them as inconsistent using only the data that existed before each restatement happened.

NBA Win-Probability Prediction Platform

It doesn't just predict who wins, it tells you how much to trust that prediction.

Modeling · Feature engineering · Production serving

An 11-season pregame win-probability pipeline with chronological splitting, a custom Elo engine, and a leakage-safe roster-continuity feature that proxies player injuries from game logs. A walk-forward backtest across 8 season cutoffs exposed a 1.7× calibration-error gap between back-to-back and rested games that the aggregate accuracy number completely hid. Shipped as a live dashboard where you pick winners against the model before its prediction is revealed.

GroundedIQ: Evidence-Grounded Analytics Copilot

Deterministic SQL and Python answers, resilient even when the LLM isn't.

Text-to-SQL · Data modeling · Guardrail design

An analytics application that converts natural-language business questions into deterministic SQL and Python, not free-form LLM answers, with evidence-backed summaries and explicit warnings.
